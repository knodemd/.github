# .github

The Knode organisation profile and the community files every Knode repository inherits.

| File | What it does |
|---|---|
| `profile/README.md` | The page at [github.com/knodemd](https://github.com/knodemd) |
| `CONTRIBUTING.md` | How to contribute |
| `CODE_OF_CONDUCT.md` | How we treat each other |
| `SECURITY.md` | How to report a vulnerability |
| `SUPPORT.md` | Where to ask for help |
| `.github/ISSUE_TEMPLATE/` | Issue forms for bugs, features and tasks |
| `.github/pull_request_template.md` | The pull request template |

A repository that adds its own version of any of these files overrides the default here.
How the project is run lives in the [handbook](https://github.com/knodemd/handbook).
