# Security policy

Knode stores people's thoughts, so security reports are a priority.

**Please don't open a public issue for a vulnerability.** Report it privately instead:

- through GitHub: *Security → Report a vulnerability* in the affected repository, or
- by email: **oss@knode.md**

Include what you found, how to reproduce it and the impact you expect. We'll acknowledge the
report within three working days, keep you updated, and credit you when the fix ships if you wish.

Only the latest release of each project is supported with security fixes.
